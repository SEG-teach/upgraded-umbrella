# All CocaCola Products

**Input Table**

| id | name      | category | launch_year |
|----|-----------|----------|-------------|
| 1  | CocaCola  | soda     | 1886        |
| 2  | Fanta     | soda     | 1940        |
| 3  | Sprite    | soda     | 1961        |

**Expected Output**

| name      |
|-----------|
| CocaCola  |
| Fanta     |
| Sprite    |
