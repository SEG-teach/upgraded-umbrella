**Input Table: products**

| id | name           | category    | launch_year |
|----|----------------|-------------|-------------|
| 1  | CocaCola       | soda        | 1886        |
| 2  | Fanta          | soda        | 1940        |
| 3  | Sprite         | soda        | 1961        |
| 4  | Minute Maid    | juice       | 1945        |

**Expected Output**

| name        | launch_year |
|-------------|-------------|
| CocaCola    | 1886        |
| Fanta       | 1940        |
| Sprite      | 1961        |
| Minute Maid | 1945        |
